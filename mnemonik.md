# Порождающие паттерны

## 1. Factory Method — Фабричный метод

### Локация
Входная дверь.

### Образ

Перед дверью стоит **огромная фабрика**.

Из её трубы вылетают готовые объекты:
- письмо;
- SMS;
- телефонное уведомление.

Но главный персонаж не выбирает объект напрямую.

На фабрике стоят разные **цеха**, и каждый цех решает, какой объект создать.

Один цех выпускает EmailNotification,
другой — SmsNotification,
третий — PushNotification.

### Что кодируем

- фабрика → создание объектов;
- общий способ создания → общий интерфейс;
- разные цеха → подклассы;
- каждый цех выбирает свой продукт → подкласс решает, какой объект создавать.

### Опорная цепочка

**ФАБРИКА → СОЗДАНИЕ → РАЗНЫЕ ЦЕХА → КОНКРЕТНЫЙ ОБЪЕКТ**

### Определение

> Factory Method — порождающий паттерн проектирования, который определяет общий интерфейс для создания объектов и позволяет подклассам решать, какой конкретный объект создавать.

### Пример

`NotificationFactory` создаёт:
`EmailNotification`, `SmsNotification`, `PushNotification`.

## 2. Abstract Factory — Абстрактная фабрика

### Локация
Зеркало.

### Образ

В зеркале отражается **огромный завод**.

Но это не один цех.

На заводе есть целые **семейства производственных линий**.

Одна линия выпускает:
- Windows Button;
- Windows Checkbox.

Другая линия выпускает:
- Mac Button;
- Mac Checkbox.

Важно: каждая фабрика создаёт **сразу несколько связанных продуктов**.

### Что кодируем

- завод → фабрика;
- несколько продуктов → семейство объектов;
- продукты связаны → связанные объекты;
- Windows и Mac → разные семейства.

### Опорная цепочка

**ЗАВОД → СЕМЕЙСТВО → НЕСКОЛЬКО СВЯЗАННЫХ ОБЪЕКТОВ**

### Определение

> Abstract Factory — порождающий паттерн проектирования, который предоставляет интерфейс для создания семейств связанных объектов, не привязывая код к конкретным классам.

### Пример

`WindowsFactory` создаёт `WindowsButton` и `WindowsCheckbox`.

`MacFactory` создаёт `MacButton` и `MacCheckbox`.

## 3. Builder — Строитель

### Локация
Вешалка.

### Образ

На вешалке висит **строитель**.

Он строит огромного робота.

Сначала прикручивает голову.

Потом руки.

Потом ноги.

Потом вставляет процессор.

Потом красит.

И только после этого говорит:

**BUILD!**

Получается готовый объект.

### Что кодируем

- строитель → Builder;
- собирает по шагам → пошаговое создание;
- много деталей → сложный объект;
- BUILD → готовый объект.

### Опорная цепочка

**СТРОИТЕЛЬ → ШАГИ → ДЕТАЛИ → ГОТОВЫЙ ОБЪЕКТ**

### Определение

> Builder — порождающий паттерн проектирования, который позволяет пошагово создавать сложный объект, отделяя процесс его создания от самого объекта.

### Пример

```java
User user = User.builder()
        .name("Ivan")
        .age(25)
        .email("ivan@example.com")
        .build();
